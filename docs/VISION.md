# Dovik Vision

## Purpose

Define a simple, statically typed programming language with native
compilation, automatic memory management, and a path to cross-platform
software development.

## Core Principles

1. Simple syntax.
2. Predictable static typing.
3. Correctness before optimization.
4. Low memory overhead.
5. Measurable performance.
6. Cross-platform design.
7. Excellent developer and AI-agent tooling.

## Non-Goals for the First Version

- Supporting every platform immediately.
- Guaranteeing faster execution than C for every workload.
- Implementing a self-hosting compiler immediately.
- Adding language features without a clear need.

## Status

Draft. Requirements and success criteria still need to be finalized.
