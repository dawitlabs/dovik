# Dovik

Dovik is an experimental, statically typed programming language designed for simplicity, native performance, and cross-platform software development.

## Vision

Dovik aims to combine:

- Python-like readability and minimal syntax
- Static typing with automatic type inference
- Native compilation and efficient execution
- Automatic memory management with low overhead
- A path toward CLI, backend, web, mobile, and desktop development
- Developer tooling designed for both humans and AI coding agents

## Status

Dovik is in the language-design and planning stage. The compiler and runtime have not yet been implemented.

## Example

```dovk
name = "Dovik"
age = 1

function greet(name)
    print("Hello, " + name)

greet(name)
```

This is illustrative syntax, not yet a guarantee of the finalized language specification.

## Project goals

- Define the language before implementing it.
- Keep syntax and semantics as simple as possible.
- Measure performance and memory usage against established languages.
- Build the compiler incrementally with automated tests.
- Expand platform support only after the core is reliable.
